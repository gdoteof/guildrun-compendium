Community statistics for Guildrun, reconstructed from the game's own log files. Drop your log folder below to add your runs — SteamIDs are scrubbed at ingest and never stored.

Where are my logs?

Windows / Linux — Steam → right-click Guildrun → Manage → Browse local files, then Guildrun_Data/Logs. Drop that folder (or the game folder) above.

macOS — the logs are inside the app bundle, at Guildrun.app/Contents/Logs. Finder won't let you open a bundle by double-clicking, so paste this in Terminal to open that folder, then drag it here:

open "$HOME/Library/Application Support/Steam/steamapps/common/Guildrun Demo/Guildrun.app/Contents/Logs"

Non-Steam install? Same path inside ~/Applications/Guildrun Demo.app. Note that ~/Library/Logs/Leyline/Guildrun/Player.log is Unity's own console log — it contains none of the run data, so uploading it finds 0 runs.

Companion app

A single-file app that follows your run live — tier badges for your current floor, full shop capture (even offers you reroll past), and automatic contribution when a run ends. Zero idle CPU, nothing installed, nothing modified.

New in v0.4: Niklas' Belly — every item his passive has eaten and the stats each one actually granted (an amplified bite reports what the game gave him, not what the item prints), as a HUD you can float over the game.

Or paste — macOS (either chip; curl skips Gatekeeper quarantine):

REL=https://github.com/gdoteof/guildrun-compendium/releases/latest/download
curl -fsSL "$REL/guildrun-companion-macos-$(uname -m | sed 's/x86_64/x64/')" \
  -o guildrun-companion && chmod +x guildrun-companion && ./guildrun-companion

Linux:

REL=https://github.com/gdoteof/guildrun-compendium/releases/latest/download
curl -fsSL $REL/guildrun-companion-linux-x64 -o guildrun-companion \
  && chmod +x guildrun-companion && ./guildrun-companion

Then play Guildrun and open http://127.0.0.1:4646/. Windows: download above and run (SmartScreen: “More info → Run anyway”, or verify checksums).
